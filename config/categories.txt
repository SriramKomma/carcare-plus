#
# Format:   CATEGORY | keyword, keyword, multi word phrase, ...
#   CATEGORY must be a ServiceCategory name (see models/ServiceCategory.java).
#   Keywords are matched as whole words, ignoring case and punctuation:
#   "brake" matches "Brake service" but not "brakes" (list both forms if needed).
#
# Scoring (ServiceCategorizer): a keyword in the title or a heading counts 3 points,
# in the description or body text 1 point. A page gets a category at 2 points or more,
# so a single passing mention in the body text is not enough.
#
# OTHER has no keywords on purpose: it is what the user picks to type a free description.
