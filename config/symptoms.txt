# CarCare+ symptoms: what a driver might TYPE, mapped to the service that fixes it.
#
# Format:   CATEGORY | symptom, symptom, multi word symptom, ...
#   CATEGORY must be a ServiceCategory name (see models/ServiceCategory.java).
#
# Matching (SymptomMatcher): a symptom matches when ALL its words appear in what the
# user typed, in any order. Words are normalized by the search Tokenizer first, so
# "won't" = "wont", "tyres" = "tire", and stop words ("the", "my"...) are ignored.
#   "battery is dead"         matches  "dead battery"
#   "car won't start at all"  matches  "won't start"
# Each matched symptom adds its number of words to the category's score, so a
# specific two-word symptom counts more than a vague one-word one.
#
# Written by the team from general car-care knowledge (not copied from any website).
